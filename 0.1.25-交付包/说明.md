# Hello Pix 0.1.25 交付包

本版修复**群聊自动翻译**：开启「群聊自动翻译」后，打开群聊会直接把会话里的消息全部自动翻译，
不再只翻译新到的消息、也不再留下需要手点的「译」按钮，并提升大量消息的翻译速度。

## 安装包（4 个）

| 文件 | 平台 | 是否进更新通道 |
| --- | --- | --- |
| `HelloPix-Setup-0.1.25.exe` | Windows x64 安装版 | ✅ 登记 |
| `HelloPix-0.1.25-portable.exe` | Windows x64 免安装版 | ❌ 只手动下载 |
| `HelloPix-0.1.25-arm64.dmg` | macOS Apple 芯片 | ✅ 登记 |
| `HelloPix-0.1.25-x64.dmg` | macOS Intel 芯片 | ✅ 登记 |

校验（应与 `SHA256SUMS.txt` 一致）：

```bash
shasum -a 256 HelloPix-*0.1.25*
# Windows:  certutil -hashfile HelloPix-Setup-0.1.25.exe SHA256
```

## 与上一版的平台差异

- **macOS Intel（x64）为新增**：此前的候选包只构建了 arm64，本版一并提供。
- **Windows 与 macOS 同一份源码**：三份 `app.asar` 逐字节相同（`sha256 a7e8ee2b…`）。

## 已知边界（务必知晓）

- **Windows 无真机验收**：开发侧无 Windows 环境，Windows 只有自动证据。
- **macOS 未公证**：首次打开需「系统设置 → 隐私与安全性 → 仍要打开」（与历史版本一致）。

## 复测

- 真机走查：见 `0.1.25-真机复测手册.md`。
- 日志采集：`./rc025-collect.sh`（把生成的压缩包回传即可分诊）。
- 本版关注埋点：`AUTO_DISPATCH`（candidates / dispatched / queued / running / chipRemoved）。

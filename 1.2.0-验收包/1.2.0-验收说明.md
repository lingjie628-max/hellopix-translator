## 三、签名状态（必须知道）

macOS 两个包是 **adhoc 签名**（`Signature=adhoc`，`TeamIdentifier=not set`），
**没有经过 Apple 公证** —— 这台构建机上没有开发者证书（`0 valid identities found`）。

和之前的 1.1.x 完全一样，不是本次引入的新问题。用户首次打开需要：

- 右键 →「打开」，或
- 系统设置 → 隐私与安全性 →「仍要打开」

dmg 内已附 `首次打开说明.txt`。要彻底消除这一步，必须先购买 Apple Developer 账号并配置证书。

## 四、与本版一起生效的服务端修复

以下问题在 1.1.2 上**能绕过或被触发**，1.2.0 配合服务端已生效：

1. **账号到期后仍能一直翻译** —— 以前只在登录时检查到期，已登录的客户端不受影响；现在每个请求都校验。
2. **分配字符被扣两次** —— 双击「分配」或网络重试会重复扣费；现在强制幂等。
3. **关闭窗口的确认按钮被 WhatsApp 浮层盖住，点不到**。
4. **桌面端重启后卡在「翻译失败」(409)** —— 结算代数只存内存，重启归零；现在落盘。
5. **管理后台改通道描述，会把翻译引擎误关掉**。

## 五、验收步骤建议

1. macOS：分别用 Apple 芯片机和 Intel 机下载对应 dmg，拖进「应用程序」（提示替换必须点**替换**），
   按「首次打开说明」放行，关于面板应显示 **1.2.0**。
2. Windows：跑 `Setup-1.2.0.exe` 安装，或直接跑免安装版，标题栏/关于面板应显示 **1.2.0**。
3. 打开任意会话发一条消息，确认翻译正常。
4. 重点回归：分配字符点两次「分配」，确认只扣一次。
5. 重点回归：把某个子账号到期时间设为过去，已登录的客户端下一次翻译应立即被拒。

## 六、回滚

旧版 1.1.2 的记录已置 `enabled = false`，**安装包仍保留在服务器**
（`/opt/hello-pix/downloads/HelloPix-1.1.2-*`、`HelloPix-Setup-1.1.2.exe`），
随时可回滚：

```sql
BEGIN;
UPDATE client_releases SET enabled = (version = '1.1.2' AND os || arch IN ('macOSarm64','macOSx64','Windowsx64')), updated_at = now();
COMMIT;
```

回滚后客户端更新接口立即重新下发 1.1.2，用户无需重装。

# Hello Pix 0.1.29 真机复测手册

> **本版重点在 Windows。** 两个报障现象都来自 Windows 用户，请在 Windows 上走完第 1～4 步。

---

## 0. 装之前先记一笔

装之前，**先在出问题的机器上打开旧版 Hello Pix**，主界面 → 设置 → 找到「客户端日志」，
把当前日志拷一份出来（或直接用 `rc029-collect.sh`）。

> 为什么要这样：这个 bug 的症状是"**检测之后**整个应用变瘸"。
> 如果先装了新版再测，就看不到旧版那份"变瘸"的证据了。
> 旧日志里应该能找到这两行之一，那是最硬的证据：
> ```
> bootstrap_look_up … MachPortRendezvousServer: Permission denied
> No rendezvous client, terminating process
> ```

---

## 1. 【核心】坏节点检测：必须 8 秒内返回，不许转圈

**准备**：一个**连得上、但不通**的 SOCKS5 节点。两种都行：
- 端口开着但服务是死的
- 地址填对但**故意把密码写错**

**步骤**：
1. 主界面 → 设置 → 线路 / 节点 → 填入上面那个坏节点。
2. 点「节点检测」。

**期望结果**（✅ / ❌）：

| 观察点 | ✅ 正确 | ❌ 错误 |
|---|---|---|
| 是否返回 | **8 秒内**给出结果 | 一直"正在检测节点…"，超过 30 秒还没动静 |
| 是否说原因 | 有明确中文原因，如「节点无响应（8 秒内没有回话）」 | 什么都不说 |
| 有没有卡死应用 | 界面照常可点 | 界面发僵 |

> **这一步是本版最核心的修复。** 老版在这里会把应用弄瘸，新版不会。

---

## 2. 【核心】坏节点检测之后，新开 WhatsApp 必须正常

**接上一步，不要重启应用**（这一点非常关键）。

**步骤**：
1. 顶栏点「+」开一个**新的 WhatsApp 实例**。
2. 等页面加载完。

**期望结果**：

| 观察点 | ✅ 正确 | ❌ 错误 |
|---|---|---|
| 页面能否加载 | 正常显示 WhatsApp 网页 | 白屏 / 一直转圈 |
| **有没有红横幅** | **没有**「Hello Pix 翻译组件未启动」 | 出现红色警告条 |
| 顶栏实例小标签 | 没有 ⚠ 标记 | 标签上带 ⚠ |
| 实际翻译 | 发一条中文，能被翻译后再发出 | 中文原样发出 |

> 这就是用户报的第二个现象。**它的触发条件是"上一次检测把应用弄坏了"** ——
> 所以必须在上一步之后紧接着测，中间不要重启。

---

## 3. 【核心】正常节点（带账号密码）必须能检测成功

**准备**：一个**正常可用**的 `socks5://` 节点，**带账号密码**。

**步骤**：点「节点检测」。

**期望结果**：

| 观察点 | ✅ 正确 | ❌ 错误 |
|---|---|---|
| 结果 | 检测**成功** | 报「这个端口不是 SOCKS5 代理」 |
| 出口 IP | 显示节点的出口 IP | —— |

> 老版有第二个隐藏 bug：**带认证的节点被误判成坏节点**（一律报"不是 SOCKS5 代理"）。
> 如果你之前"带账密的节点怎么填都检测不出来"，这一版应该好了。

---

## 4. 【核心】正常节点检测后，新开实例也必须正常

重复第 2 步，但这次前面用的是**好节点**。期望同样：无红横幅、翻译正常。

---

## 5. 回归项（确认没改坏）

| 项 | 怎么测 | 期望 |
|---|---|---|
| 发送翻译 | WhatsApp 里发中文 | 译文发出 |
| 收发翻译 | 收到英文 / 对方中文 | 能译 |
| 译文可复制 | 选中译文 → Ctrl+C → 粘贴 | 能复制出来 |
| 图文一起发 | 先打字 → 加图 → 发 | 文字**也**被翻译（0.1.28 修的） |
| 多实例隔离 | 开 2 个不同平台的实例 | 各自独立、日志分区 |
| 葡萄牙语 | 语言下拉 | 有「葡萄牙语（巴西）」与「葡萄牙语（欧洲）」两项 |

---

## 6. 收集日志发回

出了任何问题，在**出问题的那台机器**上跑：

```bash
# Windows 用 Git Bash / WSL
bash rc029-collect.sh
```

或者手动：主界面 → 设置 → 客户端日志 → 导出，连同以下信息一起发：

1. Windows 版本（`winver`）
2. 代理类型：http / socks5 / **socks5 带账号密码**
3. 复测时**卡在第几步**、屏幕上是什么
4. 检测前后的日志（**特别要"检测那一下"附近的时间段**）

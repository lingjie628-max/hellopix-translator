### 3.3 已有线路修改代理 —— 应立即生效 ★本轮核心★

0.1.10 修的就是这条（P0）：**代理地址只进 `proxyRules`，账号密码走 Electron 认证事件**；
SOCKS5 带认证通过本地回环中继（`socks-relay.js`）实现。

1. 在客户端里**新建一个线路**（标签页），**先不配代理**，点「检测」记下**直连出口 IP = A**
2. 给这条线路配置代理（你手上的真实代理，HTTP 或 SOCKS5 均可；**带账号密码的一定要测**）
3. **不要重启**，再点「检测」→ 出口 IP 应变成 **B**，且 **A ≠ B**
4. 把这条线路的代理**端口/密码改动一个字**（例如改端口），**不重启**，再检测
   —— 应**立刻**按新配置走（改错了应报错，而不是继续走旧的）

**截图**：① 直连 IP = A ② 配代理后 IP = B ③ 改动后立即生效

- [ ] 直连 IP = A
- [ ] 代理后 IP = B，A ≠ B
- [ ] 修改代理**立即生效**（不重启）

| 显示二维码 / 要重新登录 | ✅ 登录态隔离正常 |

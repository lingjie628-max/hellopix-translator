## 本版改了什么

### 修复 —— 图文消息（带图片的消息）发送时不翻译

**真机现象**：附加图片后打好中文 → 按回车 / 点发送按钮 → **中文原文直接发出去**，
消息发送成功，客户端日志里**一条发送拦截记录都没有**（说明不是翻译失败，是根本没拦）。

**根因（两层，缺一不可）**

| 层 | 位置 | 问题 |
| --- | --- | --- |
| 第 1 层 | `desktop/guest-inject.js` `composerEl()` | 只按选择器顺序取「第一个可见的输入框」。附加图片后 footer 里会出现**多个** `contenteditable`（媒体标题框、caption 框…），拿到的不是用户正在打字的那一个 → 读到的正文是空 → 发送被**静默放行**。 |
| 第 2 层 | `desktop/guest-inject.js` `onKeyDown` / `onBeforeInput` / `onClick` | 判定「事件发生在输入框里」用 `eventInComposer(event, composerEl())`。**焦点一旦没跟着切到 caption 框**（用户很可能是"先打字、再附加图片"），焦点框 ≠ 事件框 → 判定失败 → 静默放行。 |

**修法**

- 新增 `isEditableEl()`：判「能不能输入」以 **`contenteditable` 属性为准**，
  `isContentEditable` 仅作补充。原因是它是宿主派生的属性，在嵌套 contenteditable /
  shadow DOM 等场景可能给出 `undefined`，一旦假阴性就会退回错误分支。
- 新增 `boxFromEvent(event)` + `sendTargetBox(event)`：**事件优先、焦点兜底**。
  事件发生在哪个可编辑框里，就拦哪个框 —— 与焦点无关。事件框与焦点框不一致时，
  打一行 `COMPOSER_FOCUS_MISMATCH` 取证日志。
- 发送拦截三处入口（`keydown` / `beforeinput` / `click`）全部改用 `sendTargetBox(event)`。
- 新增 `SEND_NOT_INTERCEPTED` 取证日志：**凡是"本该拦下却没拦"的分支都留一行**，
  记录原因、事件类型、命中的框、事件目标与当前可见的输入框候选。
  下次同类问题不必再靠复述推断。

### 修复 —— 接收方向：带文字的图片（图文消息）正文解析

图片气泡的说明文字在没有 `span.selectable-text` 时会被漏掉。新增
`whatsappCaptionCandidates()` 作为**兜底**（仅在 `selectable-text` 一个都没找到时才启用，
避免影响"文件附件"等既有行为），并过滤掉时间戳、已读回执等 UI 节点。

### 继承自 0.1.27 —— 译文可选中、可复制

见 `0.1.27-交付包/说明.md`（应用菜单编辑角色 + 每 view 的 `before-input-event` + 右键菜单）。

## 验证（发版前实测）

- 全量测试 `node --test --test-concurrency=1 test/*.test.js`：
  **1132 项 / 1118 通过 / 0 失败**（14 跳过）。
  - 其中本次新增 5 条图文发送用例（`test/desktop-send-translate.test.js`），
    覆盖：焦点在 caption、焦点**不在** caption（真机现场）、点发送按钮、
    媒体标题框不被误当正文、`composerEl` 优先级结构守卫。
- **真 Electron / 真 Chromium 机制验收 `npm run verify:send-intercept`：15 / 15 通过**。
  - 关键证据（场景 2）：`oldPathWouldIntercept: false`（旧路径漏判 → 静默放行）
    vs `newPathIntercepts: true`（新路径命中 caption，`targetId: editable-message-text`）。
  - 同时证明 `isContentEditable` 在真 Chromium 里是 `true`、在 jsdom 里是 `undefined`
    —— 这类问题**只有真浏览器能给出可信结论**。
- 两架构 `app.asar` **逐字节相同**（`sha256 85ba295c…`）。
- 两个 DMG 均已**挂载复核**：`Info.plist` 版本 `0.1.28`，包内 `guest-inject.js`
  含 `sendTargetBox` / `boxFromEvent` / `isEditableEl` / `whatsappCaptionCandidates`。

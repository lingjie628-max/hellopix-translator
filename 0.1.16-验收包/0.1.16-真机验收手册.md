## 0. 这一版是什么

不是加功能，是把 WhatsApp 翻译桥**拆成四层并各自上闸**后，重新出的一版候选：

| 层 | 职责 | 与旧版的差别 |
|---|---|---|
| A. Message Parser | 只取真实 `messageText` | 时间/已读/View group/链接预览**不进**翻译（沿用严格 parser） |
| B. Receive 状态机 | private/group、manual/auto、历史/新消息 | 手动/自动都从 **API 调用源头**阻断，不是只改 UI |
| C. Send 状态机 | capture → block → snapshot → translate → replace → **validate** → send | 新增 `FINAL_TEXT_VALIDATED`；任何失败 **fail-closed** |
| D. Translation Renderer | 稳定身份 + loading/成功/失败/重试 + 绑定位置 | 新增**宿主硬守卫**，认不出就不画 |

### 0.1 本轮修掉的"看起来修了其实还开着"的三条

1. **「翻译中…」永久卡住** —— 真因是 `runManualTranslate` 是 `async`，调用处的同步
   `try/catch` **接不到 await 之后的异常**，chip 永远停在 busy 且无 trace。
   → 全程 `try/catch/finally` + `MANUAL_CHAIN_FORCED_RESOLVE` 兜底。
2. **译文渲染错位** —— 除裸引用外，`paint` 会**先无条件删掉「译」按钮**再判断画不画；
   且宿主解析会兜底到任意节点。 → `isMessageHost()` 硬守卫 + "先画成、再删按钮"。
3. **「重试翻译」无反应** —— 点击后无任何反馈。 → 立刻显示「正在重试…」，成功收起、失败显示「重试失败」。

### 0.2 重复点击 / 重复扣费

点「译」后 chip 进入 `busy`（`pointer-events:none`）→ 成功 `done`（按钮保留但不可点）。
再次点击**直接忽略**并留 `MANUAL_CLICK_IGNORED`。同一条消息一个动作只允许一次有效请求。

## 2. 怎么取证

**每做完一步验收操作，就跑一次采集**（只读，不改任何东西）：

macOS：

```bash
bash rc016-collect.sh before
# ...点一次「译」...
bash rc016-collect.sh after-A01-manual-click
# ...发一条消息...
bash rc016-collect.sh after-B01-send-translate
```

Windows：

```powershell
.\rc016-collect.ps1 before
# ...操作...
.\rc016-collect.ps1 after-A01-manual-click
```

产出 `rc016-evidence-<电脑名>.txt`，回传给我。我会用 `node scripts/rc-trace-triage.js` 分诊。

### 2.1 日志判读重点

- `[preload] … 翻译桥已就绪` → ✅ 桥真的起来了（**没有这行立刻停止并回传**）
- 链 A：`MANUAL_TRANSLATE_CLICK → SOURCE_EXTRACTED → TRANSLATE_STARTED → TRANSLATE_SUCCEEDED → TARGET_RELOCATED → TRANSLATION_RENDERED`
- 链 B：`SEND_CAPTURED → NATIVE_SEND_BLOCKED → SOURCE_SNAPSHOTTED → TRANSLATE_STARTED → TRANSLATE_SUCCEEDED → INPUT_REPLACED → FINAL_TEXT_VALIDATED → PROGRAMMATIC_SEND_BEGIN → PROGRAMMATIC_SEND_DONE`
- 新增可判读项：`MANUAL_CLICK_IGNORED`（重复点击被挡=正确）、
  `MANUAL_CHAIN_FORCED_RESOLVE`（finally 兜底=应查明）、
  `TRANSLATION_RENDER_TARGET_MISSING`（没找到气泡=宁可不显示）

## 4. 服务端对账（你做完后我来跑）

```sql
-- K1 手动模式未点击 → 必须 0
SELECT count(*) FROM translate_logs
 WHERE created_at > :since AND trigger = 'manual_click'
   AND chat_kind = 'group' AND instance_group_mode = 'manual';

-- K2/K3 同一动作不重复扣费
SELECT request_id, count(*) FROM translate_logs
 WHERE created_at > :since GROUP BY request_id HAVING count(*) > 1;   -- 期望空

-- K4 通道分布（GPT / DeepSeek 都应出现）
SELECT engine, count(*) FROM translate_logs WHERE created_at > :since GROUP BY engine;

-- K4 余额对账：逐账号比对，差额必须为 0
```

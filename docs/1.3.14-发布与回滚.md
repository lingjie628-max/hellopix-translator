# Hello Pix 1.3.14 客户端稳定性热修

## 发布状态

2026-11-20 构建：

- Electron 从 `33.4.11` 升级到 `45.4.1`。
- macOS ad-hoc 签名真正应用 `allow-jit`、`allow-unsigned-executable-memory`
  和 `disable-library-validation`，并开启 hardened runtime。
- 新版本首次启动时清掉旧版本残留的崩溃循环计数，避免修复版一启动就进入安全模式。
- 修正 Electron 45 下复制验证脚本的异步剪贴板与函数提取。
- 服务端代码、数据库结构本次不变。

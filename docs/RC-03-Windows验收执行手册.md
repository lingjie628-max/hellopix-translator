## 1. 安装

1. 用我给你的**唯一安装包**（SHA-256 见下），双击 `HelloPix-Setup-0.1.5.exe`
2. 安装完成后先**不要**启动

### ⚠️ 如果 Windows Defender 拦住了（大概率会遇到）

安装包**没有数字签名**（没有买代码签名证书），所以 Windows 会拦。
常见提示是：

> 「Windows Defender 已阻止可能不需要的应用」(PUA)

**说明**：这是**未签名 + 无信誉**导致的，不是检测到病毒。
PUA 比「木马」轻一档 —— 它说的是"不受欢迎"，不是"这是病毒"。
但仍然要**先核对下面的 SHA-256**，确认文件是我们发布的那个，再放行。

**推荐做法：只给这一个文件加排除项（范围最小）**

1. 先看「保护历史记录」里是不是已经被拦下/隔离了：
   `Windows 安全中心 → 病毒和威胁防护 → 保护历史记录`
   找到那条 → 点「操作」→「允许」
2. 再加排除项，避免下次又被拦：
   `病毒和威胁防护 → 病毒和威胁防护设置 → 管理设置 → 排除项`
   → `添加或删除排除项 → 添加排除项 → 文件`
   → 选中 `HelloPix-Setup-0.1.5.exe`
3. 然后重新下载一次安装包（如果刚才已被隔离，文件可能已经不完整了）
4. 再双击安装

**如果上面不管用**，才考虑临时关掉 PUA 开关（范围更大，装完请打开回去）：
`病毒和威胁防护 → 管理设置 → 阻止可能不需要的应用 → 关`

> **不要**为了装这个软件去关「实时保护」—— 那等于把整台机器敞开，
> 而需要的只是给一个文件加白名单。
>
> 我这边能提供的证据：安装包的 SHA-256 公开在 `SHA256SUMS.txt` 里，
> 你可以拿它和下载到的文件对一遍。**对不上就别装了。**

**待核对的安装包指纹**（0.1.5，构建于 2026-09-25）：

```
HelloPix-Setup-0.1.5.exe
SHA-256  599af13be98e02b58ea2fdc3a8639670fae86672d4bc57586d41d3c840034316

Hello Pix 0.1.5.exe（免安装版）
SHA-256  fc5c6a27ab47c748427dcf0271b8e8c3fdd3300a6ef1792f3ec2be98d8b2fa67
```

> **0.1.5 修了 0.1.3 上的四个客户端问题**：
> 1. **多开分区隔离** —— 0.1.3 上两个客户端窗口会共用同一个 session 分区，
>    第二个窗口打开 Telegram 会直接看到第一个的登录态。0.1.5 每个进程独占一个槽位，
>    分区名带 `s2-` / `s3-` 前缀，互不干扰。
> 2. **消息归档** —— 0.1.3 从不把消息正文上报，`messages` 表永远是空的。
>    0.1.5 会把每条消息的真实正文与时间归档。
> 3. **窗口最小尺寸** —— 0.1.3 的最小宽度是 1160px，在小屏笔记本上窗口本身
>    就要占掉半屏还多。0.1.5 降到 **900 × 560**（CDP 实测：885px 时页脚才开始溢出，
>    900 留有余量）。渲染层本来就有响应式断点（1100px 降 3 列、860px 降 2 列），
>    只是被 1160 挡住触发不到 —— 现在能正常触发了。
> 4. **关闭窗口后台运行** —— 点 × 只是把界面收进托盘，翻译继续跑；
>    要彻底退出走托盘右键「退出 Hello Pix」。托盘图标左键单击可唤回窗口。
>    可在「系统操作」菜单里关掉这个行为（关掉后 × 就是退出）。
>    **注意**：托盘创建失败时会自动退化为「关闭即退出」——
>    没有托盘就没有唤回窗口的入口，宁可退出也不能让进程变成找不到的僵尸。
>
> 单实例用户升级后**不会丢登录态**（槽位 1 的分区名与 0.1.3 完全一致）。

> 在 PowerShell 里核对：
> ```powershell
> Get-FileHash "$env:USERPROFILE\Downloads\HelloPix-Setup-0.1.5.exe" -Algorithm SHA256
> ```
> **对不上就别装了**，说明文件传错了。

## 7.5 后台运行验收（0.1.5 新增）★容易漏★

这一项要**单独测**，因为它的正确行为看起来像"程序出问题了" ——
点了 × 窗口没了，但任务管理器里进程还在。要确认这是**有意的**，且能正常唤回。

1. 确认窗口开着、Telegram 或 WhatsApp 已登录
2. 点右上角 **×**（不要用托盘菜单的退出）

**必须确认**：
- [ ] 窗口消失，但**进程还在**（任务管理器 → 详细信息，找 `Hello Pix`）
      —— 这是预期行为，不是崩溃
- [ ] 任务栏**托盘区**出现 Hello Pix 图标（Windows 上可能被折叠进 `^` 里，要展开看）
- [ ] 托盘图标**左键单击** → 窗口回来了，且**登录态还在**（不用重新收验证码/扫码）
- [ ] 关窗时弹了**一次**气泡提示「Hello Pix 仍在后台运行」（只弹一次，之后关窗不再弹）
- [ ] **验收最关键的一条**：窗口收起来之后，让别人给你发一条外文消息 →
      再唤回窗口，看**消息已经收到**（说明翻译/接收确实还在后台跑，不是假的后台）

**截图**：
- 关窗后的托盘图标（带 `^` 展开的话把展开的也截上）
- 唤回后仍在登录态的 Telegram

### 7.5.1 关掉后台运行

1. 顶部 **系统操作** → 点「关闭窗口时后台运行」（状态应变成 `○`）
2. 再点 **×**

**必须确认**：
- [ ] 这次是真的退出：任务管理器里 `Hello Pix` 进程**消失**
- [ ] 托盘图标也消失

然后再把它打开回去（点回 `◉`），确认下次关窗又变成"收进托盘"。

> **判定要点**：这一项如果出问题，性质是**进程变僵尸**（窗口没了、又没有任何
> 入口能叫回来，用户只能去任务管理器杀进程，而他多半根本不知道进程还在跑）。
> 所以下面两种情况**都算不合格**，请如实记录并截图：
> - 开了后台运行，但关窗后**进程没了**（该留没留）
> - 关掉了后台运行，但关窗后**进程还在**（该退没退，违背用户设置）

## 12. 已知会挡路的三件事（先告诉你，免得白折腾）

### ① 其余 7 个翻译引擎是"能选但不能用"

只有 **deepseek** 和 **gpt** 真正接通。如果你在下拉里选了 google / niutrans / DeepL 等，
会得到 `503 真实翻译通道尚未配置`。**验收请用 deepseek**（验收账号已经默认它）。

### ② 基础版套餐完全不能翻译

`基础版` 只绑定 google + niutrans，两个都没接通 → 该套餐商户翻译必然 403。
验收账号已在**专业版**，不受影响。这个问题等你决定怎么修。

### ③ 客户端不写日志文件

`%APPDATA%\Hello Pix\` 下只有 JSON 状态文件，**没有 .log**。
所以「翻译失败」「白屏」这类问题，客户端本地**查不到痕迹**，
只能靠截图 + 服务端数据。如果验收中出现偶发问题，请**尽量截图**，
并记下大概时间点（我能在服务端按时间反查）。

## 仅回滚官网下载

```sql
BEGIN;
UPDATE client_releases SET enabled=false, updated_at=NOW() WHERE version='1.3.10';
UPDATE client_releases SET enabled=true,  updated_at=NOW() WHERE version='1.3.9';
UPDATE app_settings
SET value='"https://pixfanyi.com/downloads/Hello%20Pix-1.3.9-arm64.dmg"'::jsonb,
    updated_at=NOW()
WHERE key='downloads.client_url';
COMMIT;
```

1.3.9 安装包仍保留在 `/opt/hello-pix/downloads/`，回滚后可立即下载。

## 回滚代码和迁移

先执行上面的下载回滚，再在维护窗口执行：

```bash
set -a
. /etc/hello-pix/hello-pix.env
set +a

cd /opt/hello-pix
node scripts/migrate.js down 1
tar -C /opt/hello-pix -xzf /root/hello-pix-release-20261118-210956/source-before-1.3.10.tar.gz
systemctl restart hello-pix.service
curl -fsS http://127.0.0.1:3000/ready
```

`054` 的 down 只删除 `count_tickets`、`count_ticket_accounts`、
`count_ticket_fans` 三张新增表，不改客户、账号、会话、充值、工单或翻译账本。

## 完整数据库恢复

只有确认数据损坏时才做完整恢复；它会覆盖回滚点之后的全部新数据：

```bash
set -a
. /etc/hello-pix/hello-pix.env
set +a

pg_restore --clean --if-exists --no-owner \
  -d "$DATABASE_URL" \
  /root/hello-pix-release-20261118-210956/database-before-1.3.10.dump
systemctl restart hello-pix.service
```

## 根因

1.3.16 使用的 Electron 45 已移除 `clipboard.writeImage` /
`clipboard.readImage`。旧代码调用：

```text
electron.clipboard.writeImage is not a function
```

Electron 45 的替代接口是：

```js
clipboard.write([
  new ClipboardItem({
    'image/png': new Blob([pngBytes], { type: 'image/png' })
  })
])
```

本次实现使用新接口，并保留旧接口兼容分支。复制完成后通过
`clipboard.has('image/png')` 验证剪贴板实际内容，而不是只确认 API 没抛异常。

## 仅回滚官网和自动更新

安装包继续保留在 `/opt/hello-pix/downloads/`，回滚不依赖重新上传：

```sql
BEGIN;
UPDATE client_releases
SET enabled=false, updated_at=NOW()
WHERE version='1.3.17';

UPDATE client_releases
SET enabled=true, updated_at=NOW()
WHERE version='1.3.16';

UPDATE app_settings
SET value='"https://pixfanyi.com/downloads/Hello%20Pix-1.3.16-arm64.dmg"'::jsonb,
    updated_at=NOW()
WHERE key='downloads.client_url';

UPDATE app_settings
SET value='"1.3.16 已发布：修复 WhatsApp 加载失败错误页、重试卡死和 ERR_CONNECTION_CLOSED 提示，并修复 WhatsApp 浏览器兼容性。"'::jsonb,
    updated_at=NOW()
WHERE key='site.announcement';
COMMIT;
```

已经安装 1.3.17 的用户不会被远程降级。停用 1.3.17 后，仍使用 1.3.16
或更早版本的用户会重新收到 1.3.16；已经升级到 1.3.17 的用户需要手动安装旧包
才能降级。

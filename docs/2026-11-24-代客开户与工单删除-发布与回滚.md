## 常规回滚

常规回滚会恢复旧前端、旧服务端文件，并撤销 `061` 迁移。已经软删除的工单会重新
出现在旧列表中，但进粉账本不会删除。

```bash
set -e
APP=/opt/hello-pix
SNAP=/root/hello-pix-release-admin-count-delete-20261124-050007

systemctl stop hello-pix
set -a
. /etc/hello-pix/hello-pix.env
set +a

cd "$APP"
node scripts/migrate.js down 1
rm -f migrations/061_count_ticket_soft_delete.js

tar -xzf "$SNAP/source-before-admin-count-delete.tar.gz" -C "$APP" \
  server/index.js \
  server/repositories/count-ticket-repository.js \
  server/routes/count-tickets.js \
  server/services/count-ticket-service.js

rm -rf "$APP/dist"
mv "$APP/dist.pre-admin-count-delete-20261124-050048" "$APP/dist"

chown -R root:root "$APP/server" "$APP/migrations" "$APP/dist"
find "$APP/server" "$APP/migrations" -type f -exec chmod 644 {} +
find "$APP/server" "$APP/migrations" -type d -exec chmod 755 {} +
find "$APP/dist" -type f -exec chmod 644 {} +
find "$APP/dist" -type d -exec chmod 755 {} +

systemctl start hello-pix
curl -fsS http://127.0.0.1:3000/ready
```

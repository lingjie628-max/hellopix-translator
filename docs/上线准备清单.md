# 上线前需要准备的账号与配置

>
> 每一节末尾都写了「拿到后填到哪」，对应超管后台的具体页面。

## 零、先明确：哪些不需要申请

| 项 | 结论 |
|---|---|
| **短信服务** | ❌ **不需要**。注册与找回密码只走邮箱验证码，短信只是后台「验证码接口」页里的配置占位，没有实际代码依赖它。 |
| 自建 SMTP 服务器 | ❌ 不建议。自建发件极易进垃圾箱，而验证邮件进垃圾箱 = 注册功能不可用。用现成的推送服务。 |

## 一、翻译通道 ✅ 必须

后台共 10 个通道，但**上线只需要先接通 3 个**，三档套餐就都能跑起来。

### 优先接通（按这个顺序申请）

#### 1️⃣ DeepSeek —— 最容易、最便宜

- **入口**：https://platform.deepseek.com/
- **资质**：手机号注册即可，**不需要企业认证**
- **付款**：支付宝 / 微信充值
- **成本**：约 ¥6/百万字符（低谷）、¥10.7（高峰）
- **拿到什么**：**API Key**（一个值）

**为什么第一个做它**：注册几分钟搞定，是所有通道里成本最低的，做基础版底座最合适。

#### 2️⃣ Gemini —— 有免费额度，不绑卡就能测

- **入口**：https://aistudio.google.com/apikey
- **资质**：Google 账号
- **付款**：**有免费额度，可以先不绑卡**
- **拿到什么**：**API Key**

**为什么第二个做它**：唯一一个能零成本验证的通道。质量好，是「AI 智能」这个卖点的支撑。

#### 3️⃣ 百度翻译 —— 国内老牌，稳定

- **入口**：https://fanyi-api.baidu.com/
- **资质**：需实名认证（个人可办）
- **付款**：有免费额度，超出后按量付费
- **拿到什么**：**APP ID + 密钥**（⚠️ **两个值**，不是只填一个）

> 百度、小牛这类国内厂商都是「APP ID + 密钥」两个字段，
> 后台表单里「密钥」那个框就是给第二个值用的。

### 后续可选（有量了再接）

| 通道 | 入口 | 备注 |
|---|---|---|
| 谷歌翻译 | https://console.cloud.google.com/ | 需先开通结算并绑国际卡；有 50 万字符/月免费额度 |
| DeepL | https://www.deepl.com/pro-api | 有免费档（50 万字符/月），欧洲语言质量标杆 |
| Grok | https://x.ai/api | 控制台在 console.x.ai |
| OpenAI | https://platform.openai.com/api-keys | 需绑卡 |
| AWS 翻译 | https://aws.amazon.com/translate/ | 需 AWS 账号 + IAM 权限 |
| Papago | https://www.ncloud.com/ | 韩语最强，但注册流程最繁琐（韩国实名） |

### 📍 拿到后填到哪

**超管后台 → 系统 → 翻译通道** → 找到对应通道 → 填 Key → 保存

系统会自动判断是否接通（凭据齐备才标记「已接通」并允许商户选用）。

> ⚠️ 系统只校验「凭据是否填了」，**不校验「key 是否有效」**。
> 填完建议在客户端实际翻一句，确认真能用。

## 二、邮箱服务 ✅ 必须

注册、找回密码都依赖它。没有它这两条链路直接不可用。

### 推荐（按好办程度排）

#### 1️⃣ 阿里云邮件推送（DirectMail）—— 国内首选

- **入口**：https://www.aliyun.com/product/directmail
- **资质**：阿里云实名认证
- **付款**：支付宝，有免费额度
- **文档**：[对接使用完全指南](https://developer.aliyun.com/article/1745955)

#### 2️⃣ 腾讯云邮件推送（SES）

- **入口**：https://cloud.tencent.com/product/ses
- **文档**：[产品概述](https://cloud.tencent.com.cn/document/product/1288/47445)
- 有国际版：https://intl.cloud.tencent.com/document/product/1084/49363

#### 3️⃣ Resend —— 开发者友好

- **入口**：https://resend.com/
- **定价**：https://resend.com/docs/knowledge-base/what-is-resend-pricing
- 界面现代、接入快，但需要国际信用卡

#### 4️⃣ SendGrid

- **入口**：https://sendgrid.com/

### ⚠️ 最关键的一步：域名验证（SPF / DKIM）

**只填 SMTP 账号是不够的。** 必须在你自己的域名（pixfanyi.com）DNS 里
添加服务商给的 SPF 和 DKIM 记录，证明「这个域名授权该服务商发信」。

不做的后果：**邮件进垃圾箱或直接被拒收** —— 用户收不到验证码，
注册功能等于不可用，但你在后台看不出任何异常。

### 需要抄下来的 5 个值

| 值 | 说明 |
|---|---|
| SMTP 服务器地址 | 形如 `smtpdm.aliyun.com` |
| 端口 | 465（SSL）或 587（STARTTLS） |
| 账号 | 通常就是发件邮箱全称 |
| **授权码** | ⚠️ **不是登录密码**，多数服务商要求单独生成 |
| 发件地址 | 必须跟验证过的域名一致，如 `noreply@pixfanyi.com` |

### 📍 拿到后填到哪

**超管后台 → 系统 → 邮件服务** → 填完点「发送测试邮件」实测一封

**同一页还有个「告警收件地址」** —— 建议填你自己的常用邮箱。
服务异常、备份失败、磁盘告急会发到这里。**不填就没有告警**，
出问题只能等用户投诉才知道。

## 三、收款方式 ✅ 必须

- **要准备什么**：你自己的 **TRC20（波场）收款地址**，形如 `T` 开头的一串
- **从哪来**：你的交易所账户或钱包（OKX / 币安 / 火币等的 USDT 充值地址）

⚠️ **地址填错 = 资金永久丢失，无法追回。**
后台保存时会做 Base58Check 校验（含校验和），能挡掉绝大多数复制错误，
但**无法识别"另一个同样合法的地址"** —— 保存后请自行核对前 6 位和后 6 位。

### 📍 填到哪

**超管后台 → 系统 → 收款方式**

## 四、其他建议准备（非技术）

| 项 | 说明 |
|---|---|
| **用户协议 / 隐私政策** | 平台会存聊天内容，法律上必须告知用户收集了什么、怎么用、存多久。建议在商户注册页放勾选确认。 |
| **退款政策** | 按字符计费的套餐，剩余字符怎么处理，建议写清楚。 |
| **客服渠道** | 商户出问题时找谁。后台已有「帮助与客服」配置项。 |

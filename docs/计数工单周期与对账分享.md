# 计数工单周期归档与对账分享

日期：2026-11-21

## 产品口径

参考独角兽 SCRM 的计数器工单，但不复制“重置即清空”的破坏性做法。

- 工单按 `cycle_no` 分周期。
- 周期重置时，当前工单出现过的客户转进同商户、同应用底库。
- 历史进粉事件永久保留。
- 新周期从 0 开始统计；底库命中的再次进线记为底库重粉。
- `今日` 仍按工单自己的 IANA 时区和每日置零时间计算。
- 账号统计拆为：今日进粉、本周期进粉、今日重粉、本周期重粉。
- 分享页只读，带随机 token，可选密码和到期时间。

## 数据迁移

`migrations/060_count_ticket_share_cycles.js`

- `count_tickets.cycle_no`
- `count_tickets.cycle_started_at`
- `count_tickets.last_cycle_reset_at`
- `count_ticket_fans.cycle_no`
- `count_ticket_shares`

工单首次进粉后的业务时区和置零时间仍保持锁定，周期重置不会解除该约束。

## 接口

```text
GET  /apis/count-tickets/:id/share
POST /apis/count-tickets/:id/share
POST /apis/count-tickets/:id/share/revoke
POST /apis/count-tickets/:id/reset-cycle
POST /apis/public/count-ticket-shares/view
```

分享 token 只存 SHA-256；密码只存 scrypt 哈希。明文 token 和自动生成密码只在
创建/轮换时返回一次。

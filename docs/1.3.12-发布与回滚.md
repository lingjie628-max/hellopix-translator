## 回滚代码与 Web

图片功能关闭不涉及数据库迁移。紧急回滚代码时：

```bash
tar -C /opt/hello-pix \
  -xzf /root/hello-pix-release-1.3.12-20261119-050122/source-before-1.3.12.tar.gz
systemctl restart hello-pix.service
curl -fsS http://127.0.0.1:3000/ready
```

完整数据库恢复只在确认数据损坏时执行：

```bash
set -a
. /etc/hello-pix/hello-pix.env
set +a
pg_restore --clean --if-exists --no-owner \
  -d "$DATABASE_URL" \
  /root/hello-pix-release-1.3.12-20261119-050122/database-before-1.3.12.dump
systemctl restart hello-pix.service
```

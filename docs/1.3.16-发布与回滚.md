## 仅回滚官网和自动更新

```sql
BEGIN;
UPDATE client_releases SET enabled=false, updated_at=NOW() WHERE version='1.3.16';
UPDATE client_releases SET enabled=true,  updated_at=NOW() WHERE version='1.3.15';
UPDATE app_settings
SET value='"https://pixfanyi.com/downloads/Hello%20Pix-1.3.15-arm64.dmg"'::jsonb,
    updated_at=NOW()
WHERE key='downloads.client_url';
COMMIT;
```

1.3.15 安装包继续保留在 `/opt/hello-pix/downloads/`，官网回滚不依赖重新上传。
已经安装 1.3.16 的用户不会被远程降级。

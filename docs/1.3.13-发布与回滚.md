## 热修说明

生产验收发现 WhatsApp DOM 时间只到分钟精度，刚绑定账号后的消息可能被误判为
“绑定前”。服务端增加 2 分钟容差后重新部署，并验证同分钟入站成功计粉。

热修前文件备份：

```text

```

## 回滚代码和迁移

```bash
set -a
. /etc/hello-pix/hello-pix.env
set +a

cd /opt/hello-pix
node scripts/migrate.js down 1
tar -C /opt/hello-pix \
  -xzf /root/hello-pix-release-1.3.13-20261119-211143/source-before-1.3.13.tar.gz
systemctl restart hello-pix.service
curl -fsS http://127.0.0.1:3000/ready
```

迁移 055 的 down 只删除合并审计表与 `event_type/direction` 两列，
不修改客户、聊天正文、充值或翻译账本。

## 怎么重新生成

```bash
cd 皮克斯多开翻译软件-完整框架报告

# 1. 重新画示意图（改了 图/生成图.py 之后）
cd 图 && python3 生成图.py && ./渲染.sh && cd ..

# 2. 重新打包 docx（改了 内容.py 之后）
python3 生成DOCX.py
```

改文字只动 `内容.py`，改排版只动 `docx引擎.py`，改插图只动 `图/生成图.py`。

## 两点说明

**样式母版**：`生成DOCX.py` 直接读取桌面上的
`PIXS_运营增强中心_完整框架_V1.0.docx` 作为模板，沿用它的
`styles.xml`、主题、编号、页眉页脚与页面设置，只替换正文与图片。
所以两份文档的字体、字号、配色、表格样式是逐字节一致的。
如果母版文件被移走，重新打包会报错 —— 把母版放回桌面即可。

**数据来源**：文中所有数字（40 张表、103 个端点、254 项测试、
9 条通道、40 张表、生产环境状态等）都取自生产服务器与代码库实测，
不是估算。图表里的进度百分比是按模块实际完工情况给的。
